# Vistora – Image Gallery

Vistora is a modern, responsive and interactive image gallery built using HTML, CSS and JavaScript.

It provides a smooth way to browse, search, filter, favorite, view and manage images with a clean and responsive user interface.

## ✨ Features

- 🖼️ Responsive image gallery
- 🔍 Search images by title
- 🏷️ Category-based filtering
- ❤️ Add and remove favorite images
- 🌙 Dark / Light theme
- ➕ Add custom images
- 🗑️ Delete custom images
- 🔎 Fullscreen lightbox
- ⬅️ Previous / Next image navigation
- ▶️ Slideshow mode
- ⬇️ Download images
- 📤 Share images
- ⌨️ Keyboard controls
- 📱 Mobile responsive design
- 💾 LocalStorage for favorites, theme and custom images
- ✨ Smooth hover effects and transitions

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Unsplash Images
